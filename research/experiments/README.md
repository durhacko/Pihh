# Experiments (spikes)

Throwaway feasibility code. **Not production; never imported from `src/`.**

- One folder per spike: `research/experiments/<issue#>-<slug>/`
- Each folder has a `README.md` with: hypothesis, how to run, result (**go / no-go / fallback**), and numbers if any.
- Spikes are allowed before idea selection. Label them clearly; they don't commit the team to an idea.
- If a spike's code is worth keeping, port it into `src/` via a normal feature issue after selection.
