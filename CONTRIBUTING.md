# Contributing

Short version for humans. Agents follow [`AGENTS.md`](AGENTS.md).

1. Work from an issue assigned to you. One issue has one owner.
2. Branch `<type>/<issue#>-<slug>` off fresh `main`.
3. Open a PR using the template, including `Closes #N`. Another teammate reviews, then you squash-merge.
4. Never commit secrets (use `.env`, see `.env.example`).

Full process, conflict rules and how to launch an agent: [`docs/development/WORKFLOW.md`](docs/development/WORKFLOW.md).
